# Finance Master

A Personal Finance Management System built with HTML, CSS, JavaScript, PHP, and MySQL.

## Features

- User registration and login
- Financial dashboard and charts
- Income and expense tracking
- Custom categories
- Monthly budgets and spending alerts
- Savings goals
- Financial reports and CSV export
- Profile, password, and currency settings

## Requirements

- XAMPP
- PHP
- MySQL
- Git

## Installation

1. Clone or download this repository into your XAMPP htdocs folder.
2. Create a MySQL database named `personal_finance_db` in phpMyAdmin.
3. Import `database.sql` into that database.
4. Copy `config/db.example.php` to `config/db.php`.
5. Configure the local database credentials in `config/db.php`.
6. Start Apache and MySQL in XAMPP.
7. Open http://localhost/finance_master/

## Security

Never commit real database credentials, passwords, or private user data.
